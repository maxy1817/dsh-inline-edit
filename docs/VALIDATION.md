## 隔离

使用桌面发行包 CLI 启动官方 Web/Host，独立 DSH_HOME、web profile，仅监听本机。未修改日常配置、会话、凭据或 PATH。

tests/fixtures/offline-provider.mjs 是本地离线适配器，走真实会话、分支、上传、模型请求和持久化链路，返回固定回显。没有使用 API Key 或外部模型。

## 真实 DSH 验收

| 操作 | 结果 |
| --- | --- |
| 保存当前模式 | 刷新和重启后保留 |
| 修改最近主消息 | 原会话 ID 不变，不增加侧边栏聊天 |
| 检查模型实际请求 | 保留前文，排除旧问题、回答和后续补充，含简短编辑说明 |
| 停止并重启 DSH | 会话可读，新问答保留，无 corrupt-log 错误 |
| 只添加附件 | 不改文字，txt 和 png 均进入同会话 |
| 只改文字 | 两个原附件保留 |
| 只移除文件 | 文字不变，图片保留；磁盘原件仍存在 |
| 运行中排队追加 | 完成后无本插件原地编辑按钮 |
| 同一轮插话 | 无原地编辑按钮，最近主消息仍可编辑 |
| 重生成主消息 | 后续补充及其回答一并替换 |
| 切回分支模式 | 新 Session 创建，原聊天保留，不误重放继承的编辑标记 |
| 原生组件 | 文件卡、图片、回答及回答操作正常 |

包安装验证使用独立 profile。原生编辑框分支模式的文字、文件增删和取消沿用 0.1.0 的独立实测记录。

## 复现

1. npm ci → npm run check → npm pack。
2. 临时 DSH_HOME 初始化 web profile，安装 tgz，启用离线适配器；不要使用日常目录。
3. 选择 inline-edit-test / offline，启动本机 Web 服务。
4. 用合成文本和小文件完成上表步骤，检查实际模型输入。
5. 停止并重新启动 DSH，打开同一个 Session。
6. 结束后停止服务，清理隔离目录。

实际验收为官方 Web/Host；Electron 专用传输、真实外部模型、其他版本、远程代理未独立测试。

底层审计日志和用量保留；原生轮次导航可能指向已替换而隐藏的旧内容。禁用插件可重显旧正文，但不会还原旧模型上下文。完整限制见 README 和 ARCHITECTURE。
